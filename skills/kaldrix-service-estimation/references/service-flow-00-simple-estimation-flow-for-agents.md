# Simple Estimation Flow for Agents

The module starts with a small company catalog and frozen project estimates. A service is added with a
manual quantity or with scopes from the BIM model; every quantity is frozen in the estimate row. There is
no supplier marketplace integration and no assignment groups. Estimate-level markup rules exist
(`kaldrix://estimation/markup-rules`). `generate_estimate_pdf` prints the same estimate PDF as the PDF
button in the Kaldrix application ("Estimate PDF" below).
