## Renovation without a drawing

Not every project needs a model. For a renovation or a pricing without a drawing create the project with
`workType=RENOVATION` (or switch an existing one with `update_project`): the MODEL step becomes optional and the
workflow goes from the address straight to the estimate, priced with manual quantities. The rest of this guide applies
only when a drawing is wanted. After the offer the process is the same for both work types (see the section
"From the accepted offer to the keys" of `kaldrix://mcp/agent-workflow`).
