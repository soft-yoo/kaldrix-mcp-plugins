# Naming Guide

Use stable, human-readable English names.

Keep names short enough for UI labels, but specific enough to identify the element without opening details.

## Floors

- `Basement`
- `Ground Floor`
- `Floor 1`
- `Floor 2`
- `Attic`
- `Roof`

For multi-building projects prefix floors with a stable building name:

- `House A / Ground Floor`
- `House A / Floor 1`
- `Office West / Ground Floor`

## Spaces

- `Living Room`
- `Kitchen`
- `Bathroom`
- `Toilet`
- `Bedroom 1`
- `Bedroom 2`
- `Home Office`
- `Corridor`
- `Hall`
- `Technical Room`

## Walls

- `North Facade`
- `South Facade`
- `Living Room - Kitchen Wall`
- `Corridor - Bathroom Wall`

Prefer relational names for shared internal walls.

## Installations

- `Ground Floor Lighting Circuit`
- `Kitchen Power Outlets`
- `Bathroom Water Route`
- `Kitchen Ventilation`

## Slabs

- `Foundation Slab`
- `Main Roof`
- `South Terrace`
- `Bedroom Balcony`
- `Main Street`
- `Visitor Parking`
- `Terrain North Slope`
