# Naming Guide

Use stable, human-readable English names: short enough for UI labels, specific enough to identify the element without opening details.

## Floors

`Basement`, `Ground Floor`, `Floor 1`, `Floor 2`, `Attic`, `Roof`. In multi-building projects prefix a stable building name: `House A / Ground Floor`, `House A / Floor 1`, `Office West / Ground Floor`.

## Spaces

`Living Room`, `Kitchen`, `Bathroom`, `Toilet`, `Bedroom 1`, `Bedroom 2`, `Home Office`, `Corridor`, `Hall`, `Technical Room`.

## Walls

`North Facade`, `South Facade`; prefer relational names for shared internal walls: `Living Room - Kitchen Wall`, `Corridor - Bathroom Wall`.

## Installations

`Ground Floor Lighting Circuit`, `Kitchen Power Outlets`, `Bathroom Water Route`, `Kitchen Ventilation`.

## Slabs

`Foundation Slab`, `Main Roof`, `South Terrace`, `Bedroom Balcony`, `Main Street`, `Visitor Parking`, `Terrain North Slope`.
