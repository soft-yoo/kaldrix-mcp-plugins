## Approximate room underfloor heating

`preview_underfloor_heating` → `create_underfloor_heating` with identical intent and the preview modelVersion.

- Backend draws SPIRAL or MEANDER as straight polyline segments with schematic corners; partitions orthogonal rooms (incl. rotated L/U outlines), subtracts exclusions and floor openings, assigns free manifold outlets, and estimates both approaches separately through actual doors/cutouts.
- Missing passages, unavailable outlets, invalid fields and stale versions block writes. Approaches are indicative; no bend arcs, physical bundle packing or port fanout. Not an installation design.
- Defaults: PE_X_16, SPIRAL, spacing 0.2 m, edge offset 0.1 m, full-loop limit 90 m, reserve 0.05, manifold outlet count 12 — estimating settings, not thermal or hydraulic sizing.
- Generic PE_X_16, PE_RT_16 and PEX_AL_PEX_16 with custom parameters need no manufacturer ID. `get_underfloor_pipe_products` gives optional versioned product identification and source data; `pipeProductId` checks ID/spec compatibility; minimumBendRadius is informational. Stored manifold dimensions do not change approximate paths or takeoff.

**One loop:** `preview_underfloor_heating_update` → `update_underfloor_heating` with its circuit UUID, exactly its room in spaceIds, `editLoopOnly=true`, optional `targetHeatingLength` (5–200 m) = pipe metres in that loop's heating field, excluding both approaches and reserve. Backend adjusts spacing within 0.05–0.5 m; loop boundaries, outlet and other loops stay unchanged. Result: requested targetHeatingLength, measured heatingLength, effectiveSpacing. Approximate (50 m may give about 55 m); quantities always use measured segments. Clear the target with editLoopOnly=true to restore the requested spacing.

**Whole room** (`editLoopOnly=false`, no targetHeatingLength): parameters can repartition fields; null targetLoopCount keeps existing IDs and may add loops; an explicit targetLoopCount can remove loops. Inspect removedCircuitIds, then `reduce_underfloor_heating` with projects.delete and confirm=true. Active estimate references block removal. No undo: going back means restoring a saved project version (`preview_project_version`, then `restore_project_version` after the user's approval). New loop IDs need explicit estimate inclusion.

**Warnings** (English guidance in every result): UNDERFLOOR_LAYOUT_APPROXIMATE = schematic routes; UNDERFLOOR_TARGET_LENGTH_DIFFERENCE = field-target difference above about 10 percent (minimum 0.1 m); UNDERFLOOR_MAX_LENGTH_EXCEEDED = manual loop over the full installed-length limit (reports installed length and threshold). They do not block saving a manual loop edit, including spacing changes without a target field length; the automatic splitter still enforces that limit.

**Quantities:** installed length = field + supply + return; purchase length = installed length × (1 + reserveFactor). Never multiply by two or add reserve again; corners create no pipe elbow fittings. Frozen estimates change only on explicit refresh; preserve prices, markups and VAT. Preview, save, read and drawings share the current layout rules and quantity engine geometry. An invalid saved loop returns a finite diagnostic with no fictitious quantity; valid loops stay readable.
