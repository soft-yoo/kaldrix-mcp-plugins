## Geometry Rules

Use finite coordinates, positive dimensions, distinct consecutive path points and actual IDs from the selected project
and floor. Keep partition segments inside the outline and use exact contact axes. After a version conflict, read and
review the new state before planning again. After a geometry error, correct the relevant arguments; do not repeat the
same failing command or try a lower-level tool to bypass its constraints.

Coordinates use project plan metres. Floor elevation is absolute. 3D height is `y`, plan Y is `z`; child base
elevations are floor-local, except measurements whose path heights are absolute project elevations.
