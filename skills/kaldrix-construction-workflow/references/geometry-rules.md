## Geometry Rules

Use finite coordinates, positive dimensions, distinct consecutive path points and actual IDs of the selected project
and floor. Keep partition segments inside the outline on exact contact axes. After a version conflict, read and review
the new state before replanning. After a geometry error, correct the relevant arguments; never repeat the same failing
command or use a lower-level tool to bypass its constraints.

Coordinates and dimensions are project plan metres. Floor elevation is absolute. 3D height is `y`, plan Y is `z`; child base
elevations are floor-local, except measurement path heights (absolute project elevations).
